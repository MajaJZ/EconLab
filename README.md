# EconLab

An open-source laboratory for experimenting with economic policy.

EconLab is a Streamlit web application that lets you adjust key policy levers and see the immediate impact on GDP growth, inflation, unemployment, and real wage growth for a selected country.

## Features

- Choose from several starting economies (Poland, Germany, USA).
- Adjust interest rate, income tax, VAT, and government spending change.
- Run a simulation and see results with progress bars and a comparison chart.
- Understand the economic intuition behind each policy variable.
